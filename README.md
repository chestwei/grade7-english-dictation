# 人教版七年级英语 · 报听写（七上 Unit 1–3）

单文件 HTML 英语听写工具，适配人教版（2024 新版）七年级上册，当前重点整理 **Unit 1–3 + 知识清单**。双击 `index.html` 即可使用，无需安装。

原始文件：`人教版七年级英语报听写(3)_含知识清单(5).html`（仓库内同时保留原名副本）。

## 功能

- 按 **Unit / Section A / Section B** 选择听写范围，支持单词、短语、句子、单词+句子四种模式
- 教材词表 + 重点短语 + 重点句（含 Grammar Focus 句型），按 2024 新版词表分节整理
- **知识清单专项**（《全品作业本》背诵本 P18–24）：Unit 1–3，小学词汇 / 重点单词 / 词形变化 / 重点短语 / 重点句型五类逐条勾选
- 发音：在线真人词典发音优先，断网自动切浏览器合成；单词与整句分链路，中文单独降级
- 可调间隔、重复遍数、语速、口音、题量；支持随机抽题、换一批、连播/暂停、重读、隐藏中文
- 自动批改（忽略大小写与标点）、错词本、历史成绩、错题重练
- 打印听写纸（可附答案）、打印批改结果
- 自定义词表；所有进度保存在浏览器 localStorage

## 使用

直接双击 `index.html`（建议用 Edge / Chrome）。若要部署到 GitHub Pages：仓库 Settings → Pages → Deploy from a branch → main / root。

在线发音需要联网；完全离线请在 Windows「设置 → 时间和语言 → 语音」安装 English 语音包，并在页面里选择「合成语音」。

## 数据说明

词句依据人教版（2024）七年级上册词表与教材重点句整理，知识清单依据《全品作业本》背诵本 P18–24。若与课本有出入，可用页面内「自定义词表」补充或替换。
